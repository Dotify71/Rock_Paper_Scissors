# Rock Paper Scissors
An awesome retro-themed Rock Paper Scissors game featuring:
- Smart AI
- Best of Series modes
- Confetti effects
- Web Audio API sound effects
- Lifetime Stats tracking

## How to Play
1. Select your preferred mode (Endless, Best of 3, etc.)
2. Choose your difficulty.
3. Click on Rock, Paper, or Scissors to make your move against the AI.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript (ES6+)
